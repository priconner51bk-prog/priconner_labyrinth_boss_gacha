# タスク一覧

## 優先順位

### P0（最優先）

- [ ] ギルド選択時の横スクロール失敗を調査・修正する
  - 現象：目的のギルドカードが画面内にない場合、横スクロール走査で選択できないことがある。
  - 対象：`scripts/task_boss_gacha_live.py` の `dynamic_guild_point()`、ADBスワイプ、画面遷移確認。
  - 分類：HYBRID
  - Local処理：スワイプ前後の画面キャプチャ、OCR結果、ADB実行結果をローカルで記録・比較する。
  - Cloud入力：失敗した1〜数回分の要約、スワイプ前後の画面ID、OCR抽出結果、座標、終了理由だけ。
  - 完了条件：全登録ギルドについて、選択カードの発見または安全停止理由の表示を確認する。

## タスクレビュー方針

大量のログ・画像・反復処理はローカルで抽出・集計し、Cloudには縮約した失敗ケースだけを渡します。分類基準とレビュー形式は、添付のタスク見直しコンテキストに従います。
