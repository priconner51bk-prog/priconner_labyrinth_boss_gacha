# 開発者向け手順

## ローカルテスト

テスト設定は `pyproject.toml` に含まれているため、プロジェクトルートからそのまま実行できます。

```powershell
python -m pytest -q
```

実機依存の `scripts/task_boss_gacha_live.py` は通常の単体テスト対象ではありません。実機を操作しない判定ロジックは `tests/` のテストで検証します。

## 変更時の確認

```powershell
python -m pytest -q
git diff --check
git status --short
```

実機フローを変更した場合は、preflight が入力を発生させずに終了すること、想定外画面や不確かな OCR で安全停止すること、許容ボス・最大試行回数・パスポート枚数が制限されること、ログとキャプチャの保存先が変わっていないことを確認します。

## 設計上の境界

`src/boss_gacha/` はボスガチャの状態遷移と判定を担当します。ADB、画面キャプチャ、OCR は `GuardedLiveActions` などの注入されたアダプターを介して利用します。共通基盤も本プロジェクト内に保持し、外部プロジェクトへの import は行いません。

設定を変更する場合は、このリポジトリの設定名・画面 ID・ROI・テンプレートの対応関係を確認し、必要なら運用ドキュメントも同時に更新します。

標準 OCR は検出・日本語認識とも `PP-OCRv4_mobile` 系モデルを使用します。モデル世代を変更する場合は、一般的な精度ではなく、このプロジェクトの実画面で同じ観測セットを使って比較し、誤読率・未検出率・処理時間を記録してください。

## コミットとレビュー

- 1 コミット 1 目的を基本にします。
- ロジック変更とドキュメント変更を分離できる場合は分離します。
- 実機操作を変更するコミットには、対象画面、入力条件、安全停止条件、テスト結果を記載します。
- キャプチャ、操作ログ、端末固有情報、秘密情報をコミットしません。
- マージ前に `git diff --check` と全テストを実行します。
