# 認証前公開チェックリスト

H2cの実行前にCloudで確認できる項目だけを定義する。認証、remote変更、pushは行わない。

- [ ] 公開先URL・著者情報・履歴方針などの公開入力値が確定している
- [ ] 公開対象と除外対象が `docs/PUBLISHING.md` と一致している
- [ ] 実機キャプチャ、OCR結果、操作ログ、モデル、ローカル設定が公開対象外である
- [ ] 著者メールと履歴方針がユーザー承認済みである
- [ ] 公開先URLがユーザー指定値である
- [ ] pushの明示承認がある

## 再開条件

公開入力値、認証環境、pushの明示承認が揃った時点でH2cを再開する。

## 安全停止

秘密情報、実機証跡、未承認メールアドレス、未確定remoteが検出された場合は公開操作を開始しない。
