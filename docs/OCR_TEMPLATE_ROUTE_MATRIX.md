# OCR・テンプレート認識経路マトリクス

注記：ガチャ本体の実行経路ではOCRを使用しない。ボス名・ギルドカード・操作対象は登録済みテンプレートと画面ガードで判定し、未認識時は安全停止する。

最終確認: 2026-09-13（静的参照調査）

| 対象 | 採用経路 | 旧/補助経路 | 安全上の境界 |
| --- | --- | --- | --- |
| 起動・通常画面 | `vision.template_screen_probe.AdbTemplateScreenProbe` | なし | 未認識・曖昧一致は入力せず停止 |
| 起動通知・起動エラー | 固定レイアウト判定 + 登録ROI | なし | 閉じる/タイトルボタンのROI確認が必須 |
| ギルドカード | 登録カード画像の `cv2.matchTemplate` | OCRの純粋な `guild_button_point` はオフライン解析用 | 一意一致・画面ガード・有限スクロール |
| ボス名 | `task_boss_gacha_live.py` の肖像テンプレート | `labyrinth_boss_ocr.py` のOCRは注入可能な汎用解析用 | 登録肖像の閾値未満は安全停止 |
| マップノード | `labyrinth_map_ocr.py` のOCR確認 + 必要な局所テンプレート | なし | OCR未確認ノードは候補化しない |
| キャラクター名 | `labyrinth_character_ocr.py` のROI OCR | なし | 低信頼・未登録名は採用しない |
| 戦闘結果・パスポート | 専用OCRパーサー | なし | 空値・不正値は停止または未判定 |

## 移行条件

- 画面遷移の入口はテンプレート画面ガードを優先し、動的なボタンROIだけで画面を確定しない。
- OCRは文字列・座標・信頼度が必要な対象に限定し、入力座標の根拠を単独で推測しない。
- 新しいテンプレート経路は、対応する固定ROI、閾値、未一致時の停止理由、回帰テストを同時に追加する。
- 実機画像がない経路は、コード・fixtureで検証済みとしても実機受入済みとは扱わない。
